# Abhinaya Darpanam — Frontend Structure

React + Vite starter scaffold for the Abhinaya Darpanam Bharatanatyam Mudra Recognition System.

## Start

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.

## Notes

- This ZIP provides the folder/file scaffold and basic Vite/React setup, not the complete UI or backend integration.
- Replace the `.placeholder.txt` asset notes with actual image/icon assets as needed.
- Set `VITE_API_BASE_URL` in `.env` to your Flask backend URL.
- API calls, authentication, camera recognition, and page contents still need implementation.
